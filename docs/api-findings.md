# 외부 API 조사 기록

## NEIS 학교기본정보

NEIS 학교기본정보 Open API는 학교명·소재지·주소·전화번호·홈페이지주소 등을 제공하며, 교육부와 16개 시도교육청이 제공하고 적재 주기는 매주이다. 문서상 기본 요청 파라미터는 `KEY`, `Type`, `pIndex`, `pSize`이며 샘플 키는 페이지 제한이 있으므로 운영 시 발급 키가 필요하다. 확인 URL: https://open.neis.go.kr/portal/data/service/selectServicePage.do?infId=OPEN17020190531110010104913&infSeq=2

현재 확인한 학교기본정보 출력 항목에는 공식 이메일 주소가 명시되어 있지 않다. 따라서 수집기는 이메일을 직접 추정하거나 무단 수집하지 않고, API 응답에 이메일 필드가 존재할 때만 저장하며 없으면 null/빈 값으로 남기는 방향이 안전하다.

## Stibee API

Stibee API v2의 Base URL은 `https://api.stibee.com/v2`이고 인증 헤더는 `AccessToken`이다. 구독자 대량 추가는 최대 10회/분, 그 외 API는 최대 1000회/분 제한이 안내되어 있다. API 권한은 요금제별로 다르며, 구독자 관리는 스탠다드 이상, 이메일 생성·편집·발송은 프로 이상, 주소록·발신자 주소 관리는 엔터프라이즈 이상으로 표시되어 있다. 확인 URL: https://developers.stibee.com/

운영 구현에서는 요청 실패·5xx·일시적 오류를 기록하고 재시도 가능한 결과와 영구 실패를 구분한다. 실제 발송은 관리자 확인 뒤에만 실행하며 수신거부 대상은 동기화 및 발송 전에 제외한다.
